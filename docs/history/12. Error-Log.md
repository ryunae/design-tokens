# Error Log

> **역할:** Backward-looking, 인시던트 단위. 최신 오류를 맨 위에 추가. 각 항목은 `ERR-NNN` + 증상/원인/해결/예방/관련 버전.
> 작업 체크박스는 [[600. Developments/lib/design-tokens/Tasks]], 릴리스 단위 이력은 [[600. Developments/lib/design-tokens/Changelog]].

## ERR-001 태그에 package.json version을 안 맞춤 — 2026-10-27
**작성:** [클로드코드]
- 증상: `v1.4.0` 태그 안의 `package.json` version이 1.3.0이었다. 이전 태그는 모두 version이 같았다.
- 원인: PR 머지 직후 version을 올리지 않고 태그를 달았다.
- 조치: version을 1.4.0으로 올리는 커밋(1d8d808)을 만들고, 원격 태그를 지운 뒤 다시 달았다. 그때 v1.4.0을 쓰는 소비자는 0곳이었고 사용자가 승인했다.
- 재발 방지: **태그 전에 `git show HEAD:package.json | grep version`으로 태그 이름과 같은지 본다.**
