## 핵심 발견 / 학습

- **레포가 public 이다**(`gh repo view` → PUBLIC). 설계·README·handoff 는 private 이라고 적혀 있다. 그래서 GEO lock 이 이번엔 codeload tarball 로 풀렸다(인증 불필요). 비공개로 되돌리면 codeload 경로가 깨지니 그때는 lock 을 git+ssh 로 다시 풀어야 한다. 가시성은 사용자 결정.

- public 전환 이유: payattention-os `52520991` — private SSH git lock 을 Vercel 이 못 받았다.
- D-006 은 규칙 추가 직후에도 깨졌다. 태그 push 를 훅으로 막는 건 안 된다 — 소비자는 태그가 있어야 핀을 올릴 수 있어 교착이다. 실제 규칙은 「태그를 달면 같은 작업 안에서 소비자 전부를 올리고 `consumers.mjs` 4/4 를 확인한 뒤 끝낸다」.
